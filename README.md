# Effects of atmospheric deposition and ocean acidification on marine microeukaryotic communities

## Introduction

This repository contains bioinformatics and statistical analysis workflows used in my undergraduate thesis.

## Research question

How do atmospheric deposition and ocean acidification affect marine microeukaryotic community structure and stability?

## Experimental design

Location:
East Indian Ocean

Treatments:
- Control
- PM
- OA
- PMA
- Fe

Culture duration:
18 days
