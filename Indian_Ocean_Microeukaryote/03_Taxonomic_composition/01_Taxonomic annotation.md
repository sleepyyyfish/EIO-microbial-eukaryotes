# Taxonomic annotation

## Description
- The representative ASV sequences generated by DADA2 were taxonomically assigned using the QIIME2 feature-classifier classify-sklearn plugin.

- A naïve Bayes classifier trained on the SILVA 138.2 SSURef NR99 database (trimmed to the 18S rRNA V4 region) was used to classify representative sequences at multiple taxonomic levels.

## Workflow

Representative sequences (rep-seqs.qza)
            │
            ▼
feature-classifier classify-sklearn
            │
            ▼
SILVA 138.2 reference classifier
            │
            ▼
taxonomy.qza
            │
            ▼
taxonomy.tsv

## Example command

```bash
qiime feature-classifier classify-sklearn \
  --i-classifier silva-138.2-18S-V4-classifier.qza \
  --i-reads rep-seqs.qza \
  --o-classification taxonomy.qza
```
Export taxonomy
```bash
qiime tools export \
  --input-path taxonomy.qza \
  --output-path taxonomy_export
```

## Notes
I used Top 50 ASV workflow as a pilot test to evaluate annotation strategies under limited computational resources.
The final analyses presented in the thesis were performed using the complete taxonomy table generated on the laboratory server.
