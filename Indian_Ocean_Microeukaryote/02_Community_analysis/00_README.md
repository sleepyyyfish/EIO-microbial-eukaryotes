# Community Diversity Analysis

This directory contains the workflow used for alpha diversity and beta diversity analyses based on the rarefied ASV table generated by QIIME2.

## Workflow

```text
Feature table (QIIME2)
        │
        ▼
Core diversity metrics (QIIME2)
        │
        ├── Alpha diversity
        │       ├── Recalculate diversity indices in R
        │       ├── Format tables for GraphPad Prism
        │       └── Statistical analysis and visualization
        │
        └── Beta diversity
                ├── Export Bray–Curtis distance matrix
                ├── PERMANOVA (QIIME2)
                ├── NMDS ordination (R)
                └── Average Bray–Curtis dissimilarity analysis (R)
```

## Directory Structure

### `QIIME2_core_metrics_protocol.md`

Core diversity analysis performed in QIIME2 using the rarefied ASV table. This step generates alpha diversity metrics, Bray–Curtis distance matrices, PCoA results, and Emperor visualizations.

### `alpha_diversity/`

Scripts for calculating alpha diversity indices, formatting output tables, and preparing data for visualization in GraphPad Prism.

Contents include:

* Alpha diversity calculation (Shannon, Simpson, Chao1, ACE, Sobs, Pielou's evenness, and Good's coverage)
* Formatting tables for downstream statistical analyses and plotting
* GraphPad Prism visualization settings

### `beta_diversity/`

Scripts and protocols for beta diversity analyses.

Contents include:

* Exporting the Bray–Curtis distance matrix from QIIME2
* PERMANOVA analysis
* NMDS ordination
* Average Bray–Curtis dissimilarity analysis

## Software

* QIIME2 (2023.9)
* R (2025.05.1)
* GraphPad Prism (10.1.2)
